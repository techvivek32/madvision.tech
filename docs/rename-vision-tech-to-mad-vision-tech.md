## 3. Needs manual handling — split markup

### `app/api/contact/route.ts` — L66

The header of the contact-form thank-you email renders the brand with the second
word italicised, matching the email signature:

```html
Vision <span style="font-style:italic;">Tech</span>
```

A blind find-and-replace will not match this (the words are separated by markup).
Decide which word carries the italic:

| Option | Renders as |
| --- | --- |
| `Mad Vision <span style="font-style:italic;">Tech</span>` | Mad Vision *Tech* |
| `Mad <span style="font-style:italic;">Vision Tech</span>` | Mad *Vision Tech* |

`public/email-signature.html` uses the same italic device for the founder's name
(`Vivek <span style="font-style:italic;">Vora</span>`) — but its brand text is the
plain `alt="Vision Tech"` and `<title>`, both of which §1 already covers.

## 5. Judgement calls worth a decision before running

**a. `data/agency.json` — 38 occurrences, the largest single block.**
Most sit inside `leads[].pitchEmailBody` / `pitchWhatsApp` — outreach copy already
drafted and, for `L-005` and `L-006`, **already sent** under the name "Vision Tech".
Renaming the drafts is correct going forward, but the two sent pitches are history;
rewriting them makes the record disagree with what the recipient actually received.
Also `brain.identity` reads *"I am the Vision Tech Agency OS."*

Additionally: this file is only the **seed**. Live data lives in Vercel Blob, and
`lib/agency-store.ts` pulls the seed in only when its `updatedAt` is newer than the
blob's. `updatedAt` currently reads `2026-07-21T15:35:50+05:30`, so unless it is
bumped, the rename will not reach the live `/admin` dashboard.

**b. `docs/daily-agency-cycle-prompt.md` — 3 occurrences.**
This is the instruction prompt for the daily cloud routine. If it is not updated,
every future cycle will write *new* leads and pitches signed "Vision Tech", silently
undoing the rename in `data/agency.json` on the next run.

**c. Email sender names — `app/api/contact/route.ts`, `app/api/agency/outreach/route.ts`.**
These are the `from` display names recipients actually see in their inbox:
`"Vision Tech Website"`, `"Vision Tech"`, `"Vivek Vora — Vision Tech"`.
Changing them changes how mail from you is labelled — and mid-campaign, a lead who
got a pitch from "Vision Tech" will see the follow-up arrive from a different name.

**d. Marquee strip lengths.** Section 2 strings get 4 characters longer each. The
strips loop on a fixed CSS duration (`animate-marquee` etc. in `app/globals.css`),
so the scroll speed per character shifts slightly. Cosmetic, but check
`components/marquee-section.tsx` defaults and the footer watermark after the change.

**e. Domain and logo.** `madvision.tech`, the `logo.jpg` artwork, the Vercel project
and the Gmail sender identity all carry the old wordmark in places text replacement
cannot reach. Out of scope here, but the rename is not visually complete without them.
